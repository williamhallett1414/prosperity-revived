06 / CROSS-BOT CONSISTENCY
System Rules

All five backgrounds share the same underlying visual grammar. Individual personalities are expressed through palette, geometry, and light quality — never through structural deviation.

RULE 01

Three-Zone Composition

Every background uses the same vertical zone structure. Top 30%: character energy, architectural or environmental mood-setter. Middle 40%: clear zone, avatar only. Bottom 30%: ground anchor, heaviest visual weight.

RULE 02

Flat Art, Layered Depth

No gradients within individual cartoon elements. Depth comes from opacity layering between elements. 2–3px outlines on primary shapes, 1px on details. All corners 4–8px radius — never sharp 90° or fully circular.

RULE 03

Speaking State Response

When the bot speaks: ambient light overlays +0.10 opacity (400ms ease). Particle systems speed up 1.4×. Background radial glow behind avatar +0.15. No structural changes — luminosity only.

RULE 04

Performance Budget

SVG only — no canvas, no WebGL. Max 120 DOM nodes per background. CSS animations only, no JS libraries. 60fps target on iPhone 12 / Pixel 6. prefers-reduced-motion: all animations off, static illustration only.

RULE 05

Colour Temperature Logic

Each bot's temperature is intentional: Gideon 3200K (warmth, candlelight), Daniel 4000K (kitchen warmth), David 6500K (cool focus), Hannah 2700K (intimate amber), Paul 3800K (dawn, possibility).

RULE 06

Component Architecture

Single entry component: <BotBackground character="…" />. Pure presentational — no state, memo-wrapped, no re-renders on message updates. Accepts speaking, listening, thinking props for state-driven light adjustments.

Recommended React Component Structure
// src/components/avatar/BotBackground.jsx import React, { memo } from 'react'; import GideonBackground from './backgrounds/GideonBackground'; import DanielBackground from './backgrounds/DanielBackground'; import DavidBackground from './backgrounds/DavidBackground'; import HannahBackground from './backgrounds/HannahBackground'; import PaulBackground from './backgrounds/PaulBackground'; const BACKGROUNDS = { gideon: GideonBackground, chef: DanielBackground, coach: DavidBackground, hannah: HannahBackground, paul: PaulBackground, }; const BotBackground = memo(({ character, speaking, listening, thinking }) => { const Background = BACKGROUNDS[character] ?? GideonBackground; return <Background speaking={speaking} listening={listening} thinking={thinking} />; }); export default BotBackground;
